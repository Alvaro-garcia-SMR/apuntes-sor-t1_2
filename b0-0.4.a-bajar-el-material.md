## 🤔 Respuestas a las preguntas

1. Use this template crea un repositorio nuevo en tu cuenta con los mismos archivos que la plantilla, sin historial previo ni vínculo de fork. Trabajas sobre el tuyo, no sobre el del profesor.
2. No pide contraseña porque clonar un repositorio público por HTTPS no requiere autenticación. Sí la pediría para clonar uno privado o para hacer `push` a cualquiera. GitHub ya no admite la contraseña de la cuenta, y pide un token de acceso personal.
3. La carpeta clonada tiene la carpeta oculta .git, que guarda el historial y el enlace con el repositorio remoto. Sin ella no puedes hacer `commit`, no puedes sincronizar con `push` y `pull`, y no puedes ver el historial, las ramas ni las diferencias (`log`, `diff`, `branch`).
4. Haces commit y push en el aula, y el sábado en casa haces git pull (o git clone si no tienes el repositorio). Si no subes los cambios, la nota se queda en el ordenador del aula.
