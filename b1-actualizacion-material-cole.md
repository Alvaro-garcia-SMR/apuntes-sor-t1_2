**2.** El segundo argumento de `git clone` sirve para indicar el nombre de la carpeta donde se guardará el repositorio. Sin él, Git utilizaría automáticamente el nombre del repositorio original.

**3.** Se puede borrar la carpeta local y recuperarla volviendo a clonar el repositorio desde GitHub. Si borras el repositorio de GitHub, no puedes recuperarlo simplemente clonándolo.

**5.** `Use this template` permite crear un repositorio propio copiando el contenido de otro repositorio. Un fork crea una copia vinculada al repositorio original, mientras que una plantilla crea un repositorio independiente.
